INSTALLATION METHODS DOCUMENTED
================================================================================

Automated Method (via setup.sh):
  chmod +x setup.sh
  ./setup.sh
  • Automatically detects Linux distribution
  • Installs appropriate packages
  • Adds user to video group
  • Ready to build

Ubuntu / Debian:
  sudo apt-get update
  sudo apt-get install -y \
      build-essential cmake libgtk-3-dev libgdk-pixbuf2.0-dev \
      libopencv-dev libsqlite3-dev pkg-config

Fedora / RHEL / CentOS:
  sudo dnf install -y \
      gcc-c++ cmake gtk3-devel gdk-pixbuf2-devel \
      opencv-devel sqlite-devel pkg-config

Arch Linux:
  sudo pacman -S \
      base-devel cmake gtk3 gdk-pixbuf2 opencv sqlite pkg-config

macOS (via Homebrew - not officially supported):
  brew install gtk+3 opencv sqlite pkg-config
